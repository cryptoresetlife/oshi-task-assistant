# 接入当前已经登录的 Chrome

此扩展不要求重新登录、不重启 Chrome，也不导出 Cookie。它连接本机助手，在当前 Chrome 配置中创建 Oshi 和 X 工作标签页，复用已有登录状态。已有标签页会保留。

## 一次性加载

1. 启动 v0.1.7 或更新版本的助手，打开 http://127.0.0.1:18745。
2. 在**已经登录目标账号的 Chrome** 地址栏输入 `chrome://extensions`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择软件目录中的 `extension` 文件夹（其中有 manifest.json）。不要选择 ZIP 文件或软件上层目录。
4. Chrome 会显示扩展权限。扩展使用 `debugger` 操作工作标签页，使用 `tabs` 核对这些标签页的网址，使用 `storage` 保存环境标识和助手地址；连接码不会保存。Chrome 权限提示的范围比本工具实际使用范围更广，请检查源码后再加载。

## 每次连接

1. 在助手页面展开“直接接入已登录的 Chrome”，点击“显示扩展目录和连接码”，复制连接码。
2. 在 Chrome 工具栏的拼图菜单找到“Oshi 助手 · 已登录 Chrome 接入”。填写助手地址、连接码和可选环境名称，点“连接当前 Chrome”。
3. 回助手点“刷新环境”，选中“已登录 Chrome（扩展）”，再点“连接环境”。确认读取的账号正确后选择任务。

只连接不会点赞或发帖，仍需在助手中明确运行任务。Chrome 提示“此扩展已开始调试此浏览器”属于正常提示；点击取消会中断对应工作标签页。扩展里点“断开”会停止接入，保留页面供检查。关闭助手或重启 Chrome 后，请重新连接；助手重启会更换连接码。

不要把连接码发给别人。扩展只接受 `127.0.0.1` 本机助手地址，不向远程服务器建立连接。不同 Chrome 用户配置需要各自加载并连接一次；同一用户配置的多个窗口共享登录账号，不是多个独立账号。

## 排查

- 连接失败：先确认助手正在运行、地址端口正确，重新复制连接码；不要在其他浏览器配置的扩展中使用当前窗口的账号预期。
- 提示需要登录：确认登录的是同一 Chrome 用户配置中的 Oshi 和 X，扩展不会把其他配置的登录状态搬过来。
- 任务中断：检查是否关闭了工作标签页、取消调试提示条或打开了该标签页的开发者工具。
- 页面离开 Oshi / X：扩展停止控制该工作标签页。

Chrome API 参考：https://developer.chrome.com/docs/extensions/reference/api/debugger
